# STA 5107 Computational Methods in Statistics II

This folder contains the code files for the programming components of each homework assignment.  
The topics covered in each homework are summarized below.

| Homework | Topic |
|----------|--------|
| 1 | PCA |
| 2 | Fisher’s discriminant analysis, homogeneous Poisson counting process, and random walk |
| 3 | Homogeneous Markov chain |
| 4 | Metropolis–Hastings algorithm and posterior distribution |
| 5 | Gibbs sampling |
| 6 | Nonlinear systems and sequential Monte Carlo |
| 7 | Kalman filter |
| 8 | Optimization and simulated annealing algorithm |
| 9 | Dynamic programming and spatial dynamic programming |
| Final | Reversible jump Markov chain Monte Carlo algorithm |
